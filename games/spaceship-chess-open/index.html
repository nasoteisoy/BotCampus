❓ How to play

🎯 Trap the enemy 🛰️ Command station (checkmate).

🌌 No boards: ships float in open space. The space is still 8 levels of 8×8 (tiny dim dots mark the spots). 🔵 Blue starts on levels 1–2 (rows 1–2), 🟠 Orange on levels 7–8 (rows 7–8). Blue moves first.

👀 Always on, no tap needed:

  • ● blue dot = a 🔵 ship can fly there
  • ◆ orange diamond = a 🟠 ship can fly there
  • ━▶ red beam + 🔵/🟠 arrow = attack (a legal capture)
  • ◯ pulsing red ring = ship under attack
  • ⚠️ big red cage + beams = Command station in check

🔵 / 🟠 / 🔵🟠 (top right) = show mine, enemy or both. The red number = attacks ready.

👆 Tap your ship → its moves light up bright, the rest dims → tap a pad. ● move ● capture.

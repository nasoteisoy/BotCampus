# Harmony Trainer

Practice singing harmony over a melody. Mic pitch meter, graded drills, public-domain songs.

## Run

Serve this folder over HTTP (required for mic + modules), then open on phone or PC.

## Validate intervals

```bash
node scripts/validate-intervals.js
```

## Notes

- Wear headphones so the mic hears your voice, not the piano
- Octave control defaults to male range (−1)
- Best scores stay in localStorage on this device

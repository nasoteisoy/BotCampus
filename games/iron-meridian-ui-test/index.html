Iron Meridian 8: three different UIs

Same map, same rules, same sample turn. Only the way you play changes. Try each one: pick a battalion, give it an order, buy something, send the turn, read the result. Test pages. Not the real game.

A. Guided turnThe game walks you through it: Buy, then one battalion at a time, then each battle, then send. Big buttons, plain words, no menus. B. Tap the mapNo menu bar. Tap a territory or a counter and a sheet slides up with the actions you can do there, each with a one-line reason. C. Army listStart from your battalions as cards that say in words how strong they are. Tap a card to give orders. The map is only for picking a destination.

Each page is one file with its own map art. Nothing is saved.

🔒 Security basics

Safe text render vs a dangerous pattern called out only in comments / README. No live XSS.

Try pasting markup — it must appear as text, not execute.

Called out — do not implement: 
// DANGEROUS — XSS sink (shown for education only)
el.innerHTML = userControlledString;

Prefer textContent, sanitized libraries with a clear policy, or framework auto-escaping. Never “demo” the bad path in production Pages.
